A sample that runs its own script

Inline <script> means every edit rebuilds the frame rather than patching it — innerHTML never executes scripts it inserts.

<button id="go">Click me</button>
<p id="out"></p>
<script>
  let n = 0
  go.onclick = () => out.textContent = `clicked ${++n}`
</script>
